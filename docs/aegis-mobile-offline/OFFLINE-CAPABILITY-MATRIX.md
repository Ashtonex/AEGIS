# AEGIS Offline Capability Matrix

| Module | Offline Read | Offline Draft Creation | Offline Submission (Queued) | Online Only Actions |
| :--- | :--- | :--- | :--- | :--- |
| **Site Operations** | Cached daily reports, targets, briefing | Daily report draft, plant request draft | Daily report creation, site plant request | Formal managerial report approval |
| **Inventory / Stores** | Catalog snapshots, store locations | Stock count draft, material issue draft | Stock count verification, store requisition | Ledger reconciliation, financial posting |
| **Workforce** | Employee roster, active crew list | Daily attendance register draft | Daily attendance submission | Payroll posting, wage finalization |
| **Plant & Equipment** | Equipment list, active assignments | Pre-start inspection draft, shift log | Shift log & inspection submission | Maintenance approval, lease billing |
| **Fleet** | Vehicle registry | Mileage log draft, fuel receipt draft | Trip log submission | Fleet purchase, asset decommissioning |
| **Procurement** | Approved item catalog | Purchase requisition draft | Requisition submission | PO approval, financial commitment |
| **Finance / Accounts**| Read-only cached summaries | None | None | All journals, payments, ledger edits |
| **Executive** | Read-only dashboard snapshot | None | None | All approvals, budget authorizations |
